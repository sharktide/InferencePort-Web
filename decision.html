P2G API guide

Decisions, with probabilities.

Classify requests, evaluate gates and score outcomes using typed questions on the unified API.

Open the console → Playground → Decisions · Browse models

One endpoint, configurable providers

POST /v1/systemone accepts a model, text or JSON state, and named questions. Microsoft Decision 1 is available through the Foundry East US integration. Discover decision models with GET /v1/decision/models or GET /v1/models.

Authenticate with your InferencePort bearer token or API key. Add X-InferencePort-Org to bill an organization. Decision models use P2G wallet credits and have their own modality policy.

Ask typed questions

  • choice: select a named criterion and inspect the returned probabilities.
  • noul: evaluate a question as a value from zero to one.
  • score: score against an ordered list of criteria.
{
  "model": "microsoft/decision-1",
  "state": "I was charged twice. Please refund me.",
  "questions": {
    "team": {
      "type": "choice",
      "instructions": "Which team should handle this request?",
      "criteria": {
        "billing": "Charges, invoices and refunds",
        "support": "How-to and account questions"
      }
    },
    "refund": {
      "type": "noul",
      "instructions": "Is the customer requesting a refund?"
    }
  }
}

Save the request as request.json, then call your configured API base:

curl "$INFERENCEPORT_API_BASE/v1/systemone" \
  -H "Authorization: Bearer $INFERENCEPORT_API_KEY" \
  -H 'Content-Type: application/json' \
  --data-binary @request.json

Results preserve the provider’s answers object. Read usage.input_tokens and usage.payg_credits_charged for usage and cost. Requests support up to 64 questions, 2–64 choice or score criteria, and 1 MB of serialized state/questions.

Try it in the console or CLI

The Decisions playground lets you select a model, edit state and question JSON, inspect choices and probabilities, and download the complete response.

ipx p2g models --type decision
ipx p2g prices --type decision
ipx p2g decision --file request.json --output result.json
cat request.json | ipx p2g decision --file - --json

Pricing and provider setup

Decision models bill per input token at the configured catalog rate. Microsoft Decision 1 starts at $0.042 per million input tokens. Check the live model catalog for current prices. Normal account discounts, markups and wallet rounding apply. Charges round to 0.0001 credits. Missing provider usage is estimated across questions; failed provider requests are not charged.

Operators manage providers and retail rates in InferencePort-Lightning/src/models/decision.json. The Foundry entry uses the server-side FOUNDRY_KEY secret. Add System One compatible deployments such as D3 or JEV with their URL, upstream ID, authentication variable and desired input-token rate. Clients continue using their InferencePort credentials.
