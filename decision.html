One endpoint, configurable providers

POST /v1/systemone accepts a model, text or JSON state, and named questions. Microsoft Decision 1 is available through the Foundry East US integration. Discover decision models with GET /v1/decision/models or GET /v1/models.

Use an InferencePort bearer token or API key in the authorization header. To bill an organization, add X-InferencePort-Org: your-org-slug. Decision models use P2G wallet credits and follow the account’s decision-modality policy.

Send a decision request

Set your API key in the shell, save the JSON body as request.json, then send it with curl. Keep the key private.

export INFERENCEPORT_API_KEY="your-api-key"
{
  "model": "microsoft/decision-1",
  "state": "I was charged twice. Please refund me.",
  "questions": {
    "team": {
      "type": "choice",
      "instructions": "Which team should handle this request?",
      "criteria": {
        "billing": "Charges, invoices and refunds",
        "support": "How-to and account questions"
      }
    },
    "refund": {
      "type": "noul",
      "instructions": "Is the customer requesting a refund?"
    }
  }
}
curl https://api.inferenceport.ai/v1/systemone \
  -H "Authorization: Bearer $INFERENCEPORT_API_KEY" \
  -H "Content-Type: application/json" \
  --data-binary @request.json

For organization billing, add -H "X-InferencePort-Org: your-org-slug" to the curl command.

Question types and results

  • choice selects among named criteria. The answer includes a choice; when supplied, probabilities gives a value for each criterion.
  • noul returns a value from zero to one in noul, useful for a yes/no gate or graded assessment.
  • score rates an ordered list of criteria. Read its score and any returned probabilities.

Answers are returned under answers, keyed by your question names. The response also reports usage such as usage.input_tokens and usage.payg_credits_charged. The console displays choices, probabilities, scores and the full provider response.

Try it in the console or CLI

In the console, sign in, open Playground, select P2G API, then choose Decisions. Enter state and question JSON, evaluate, and download the full response.

CLI examples:

ipx p2g models --type decision
ipx p2g prices --type decision
ipx p2g decision --file request.json --output result.json
cat request.json | ipx p2g decision --file - --json

Requests support up to 64 questions, 2–64 criteria for choice or score, and 1 MB of serialized state and questions.

Pricing and billing

Decision models bill per input token at the configured catalog rate. Microsoft Decision 1 starts at $0.042 per million input tokens; check the live model catalog for current rates. Account discounts, markups and wallet rounding apply. Charges round to 0.0001 credits. If provider usage is missing, usage is estimated across questions; failed provider requests are not charged.

Personal requests use your P2G wallet. Add X-InferencePort-Org with an organization slug to bill that organization, subject to its billing setup and modality policy.

Operator configuration reference

Operators manage providers and retail rates in InferencePort-Lightning/src/models/decision.json. The Foundry entry uses the server-side FOUNDRY_KEY secret. A System One compatible deployment can be configured with its URL, upstream ID, authentication variable and input-token rate. Clients continue to use InferencePort credentials.
