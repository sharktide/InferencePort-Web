Safeguards and responsibilities

Security overview

InferencePort uses authentication, API-key controls, organization roles, request and rate limits, security diagnostics, and other service-specific protections. The desktop application and CLI can execute local models without sending their prompts through our hosted inference APIs; optional cloud services, sync and authentication do communicate with remote services.

Protect your credentials

Keep API keys and access tokens confidential and revoke them if compromised. Local CLI credential files are not guaranteed encrypted. If you expose a model server, configure network and transport protection carefully; the CLI proxy does not implement the desktop proxy's optional encrypted-session handshake.

Use trusted integrations

Cloud model routing may involve external inference providers, and agents and MCP tools may send context to connected third parties. Review their policies and permissions. AI Shield offers detection and risk scoring, not a guarantee that all harmful content or threats will be caught.

Report a vulnerability

Send confidential reports to security@vorugaluav.resend.app. Avoid publishing undisclosed vulnerabilities or any sensitive personal information in public issue trackers.
