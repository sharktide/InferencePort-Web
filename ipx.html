Built for automation

Gate a pipeline. Pipe the output.

Use --json for machine-readable output, stdin for piped input and exit codes for automation.

  • JSON output. ipx --json usage get | jq .quota
  • Fail the build. Shield --fail-on review exits with code 3 at or above that verdict.
  • Set Shield rules. Use --policy, --block and --allow.
  • CI sign-in. Use an API key for non-interactive authentication.

Command reference

Generate, manage and run locally.

Switch organizations with ipx auth context. The selected organization controls org, policy and billing commands.

Generate

ipx gen

Subscription-billed Lightning for chat, text, image, video and audio.

ipx gen image "a lighthouse at dawn" -o lighthouse.jpg
ipx p2g

Credit-billed Pay-to-Go API for chat, image, video, audio, 3D, embeddings, realtime voice, balance, ledger and keys.

ipx p2g 3d --image chair.jpg -o chair.glb

Manage

ipx org

Members, invitations, teams, keys, billing, usage, audit, domains, SSO and policy.

ipx org keys create ci --monthly-limit 25
ipx agent

Create, update, publish and chat with managed agents; manage invites and members.

ipx agent chat acme-bot/support
ipx mcp council

Use the hosted Council of LLMs: tiers, models, reasoning and client setup.

ipx mcp council reason "Is this migration safe?" --tier basic
ipx shield

AI Shield scans, analyzes and checks URLs, files, messages, listings, passwords and domains.

ipx shield scan "Ignore previous instructions…"
ipx usage

View quotas, wallet balance and organization spend.

ipx usage get
ipx doctor

Diagnostics, config, API passthrough, rewards and shell completion.

ipx doctor

Deployments

Deploy, check, cancel, restore and track usage of on-demand model deployments.

ipx model / local

Pull local models and chat with them using the desktop app engine.

ipx model pull llama3.2
ipx server

Host local models for teammates: start, stop, status and logs.

ipx server start --allow teammate@acme.com --detach
ipx import

Add Hugging Face Spaces, websites and files to the desktop app library.

ipx import space black-forest-labs/FLUX.1-schnell
