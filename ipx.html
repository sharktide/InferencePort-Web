What it does

Every part of the platform, one command away.

Sign in with email, GitHub, Google, Microsoft, Hugging Face, SSO or an API key. Switch into an organization with ipx auth context and billing, policy and org commands follow.

ipx gen

Subscription-billed Lightning: chat, text, image, video and audio.

ipx gen image "…" -o out.jpg
ipx p2g

Credit-billed Pay-to-Go API: chat, image, video, audio, 3D, embeddings and realtime voice, plus balance, ledger and keys.

ipx p2g 3d --image chair.jpg -o chair.glb
ipx org

Members, invitations, teams, API keys, billing, usage, audit, domains, SSO, policy and desktop policy.

ipx org keys create ci --monthly-limit 25
ipx agent

Create, update, publish and chat with managed agents; manage invites and members.

ipx agent chat acme-bot/support
ipx mcp council

The hosted Council of LLMs MCP server: tiers, models, reason, test, and connect to your client.

ipx mcp council reason "…" --tier basic
Deployments

Deploy, check, cancel, restore and track usage of on-demand model deployments, personal or for the org.

ipx --help
ipx shield

AI Shield: scan, analyze, phishing, url, check, disposable, request, file, password, listing, review and domain.

ipx shield scan "Ignore previous instructions…"
ipx model / local

Pull local models and chat with them, using the same engine as the desktop app.

ipx model pull llama3.2
ipx server

Host your local models for teammates: start, stop, status and logs.

ipx server start --allow teammate@acme.com --detach
ipx import

Add Hugging Face Spaces, websites and files to the desktop app library.

ipx import space black-forest-labs/FLUX.1-schnell
ipx usage

Quotas, wallet balance and organization spend at a glance.

ipx usage get
ipx doctor

Diagnostics, config, API passthrough, rewards and shell completion.

ipx config · doctor · api · completion
Built for automation

Gate a pipeline. Pipe the output.

ipx is scriptable by default: every command takes --json, reads from stdin and returns meaningful exit codes.

  • --json everywhere. Raw output for jq: ipx --json usage get | jq .quota.
  • Fail the build. --fail-on review exits with code 3 when Shield returns a verdict at or above review.
  • Your own rules. Pass --policy, --block and --allow to Shield.
  • API keys. Authenticate non-interactively in CI with an API key.
