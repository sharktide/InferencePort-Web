One API. Every modality.

A unified, credit-metered API for production workloads. Text, image, video, audio, and 3D — all through a single OpenAI-compatible endpoint.

🔌
OpenAI-Compatible Endpoint
Drop-in replacement for existing OpenAI integrations. Use your current SDK, libraries, and tools with zero code changes.
✎
Text Generation
Access frontier text models including Lightning at up to 1,000 words/sec. Supports streaming, function calling, and multi-turn conversations.
🎨
Image Generation
Generate images from text prompts. Support for multiple aspect ratios, styles, and quality levels. Batch generation for production use.
🎥
Video Generation
Create videos from text descriptions. Configurable duration, resolution, and frame rate. Ideal for content creation and media pipelines.
🎵
Audio Generation
Text-to-speech and audio synthesis from prompts. Multiple voice options, configurable speed, and high-fidelity output.
🔮
3D Generation

Credit-Based Billing

Usage Analytics

🛡
Rate Limiting & Quotas
Configurable rate limits per API key. Set spending caps, request quotas, and model-specific limits. Automatic throttling.

Enterprise & Production

💻 InferencePort AI App

Chat. Self-Host. Manage.

The all-in-one desktop app for end users and teams. Chat with Lightning-speed models, self-host your own AI server, and manage 45,000+ open-source models from Hugging Face.

⚡
Chat with Lightning Models
Talk to our Lightning-powered models at up to 1,000 words per second. Optimized for speed with smart provider routing that selects the best backend for every response.
💬
Generation API Chat
The default cloud chat path. Uses your subscription plan quotas with an OpenAI-compatible endpoint. Optimized for everyday chatting with access to all frontier models.
🌐
Self-Hosted AI Server
Run local LLMs on your own hardware and invite your entire team by email. Authenticate via accounts or custom API keys. Keep all data on-premise.
📦
Model Marketplace
Browse, download, and run community models and tools directly from the built-in marketplace. Filter by type, size, and capability. One-click install.
💻
Local Models (Ollama)
100% on-device, fully offline AI. Full Ollama compatibility with access to thousands of open-source models. Unlimited local chat with zero data leaving your machine.
🎯
45,000+ Hugging Face Models
Chat with any one of the compatible 45,000+ open-source models on Hugging Face. Requires compatible model metadata and local hardware support.
👥
Team Management
Invite team members via email, assign roles, and manage access to self-hosted servers. Custom API keys for programmatic access. Monitor usage across your org.
🚀
Remote Server Connection
Connect to remote Ollama servers and self-hosted instances from anywhere. Manage multiple server endpoints and switch between them on the fly.
🌐
Hugging Face Spaces
Access and run Hugging Face Spaces directly from the app. Deploy demos, experiment with community models, and run interactive ML applications.
