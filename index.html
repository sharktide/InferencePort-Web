Pay-to-Go API

One endpoint for every kind of AI.

Point your existing OpenAI SDK at InferencePort and call text, image, video, audio, 3D, embedding and realtime voice models. You pay per request from a prepaid credit wallet — separate from any chat subscription.

  • OpenAI-compatible. Same SDKs and tools; change the base URL and key.
  • Text with streaming and function calling, including Lightning models.
  • Image, video, audio and 3D generation through the same account.
  • Embeddings and realtime. /v1/embeddings for vectors and a /v1/realtime WebSocket for live voice and transcription.
  • Predictable spend. Buy credit packs; usage and cost are visible per model in the console.
  • Model catalog API. List models programmatically by type and capability.

Managed agents

Launch AI agents without running any infrastructure.

Define an agent once — a model, instructions and the tools it can use — and InferencePort hosts it. Your app calls it through the same API as any model.

  • Hosted for you. Pick a backing model, write a system prompt, and attach MCP servers for tools.
  • Call it like a model. Use agent/<username>/<agent-id> with the chat completions API.
  • Share or keep private. Publish to the registry, list it as unlisted, or keep it to yourself.
  • You choose who pays. Callers pay for their own usage, or you cover it as the owner.
  • Built for teams. Invite collaborators and run agents under your organization’s wallet and policies.

Council MCP server

Give any AI assistant a council of models.

One tool call sends a hard problem to many models. They answer in parallel, critique each other, and a panel of judges returns a single, stronger answer — right inside the tools you already use.

  • Works with your client. Claude Code, Cursor, VS Code, Claude Desktop, or your own MCP agent.
  • Tiers. Choose how many and how strong the models and judges are, with 1–3 review rounds or your own picks.
  • Sign in your way. OAuth, or an API key as a Bearer token.
  • Clear billing. Per-token usage plus a flat surcharge, billed to you or your organization under its policies.

AI Shield

Know who you can trust, in one API call.

Send whatever you know about a sign-up, login or message. Shield returns a risk score, a confidence level, plain-English reasons and a recommended action in under a second.

  • Signup protection. Bots, fake accounts, trial farming and referral abuse.
  • Identity. Linked accounts, duplicates and ban evasion.
  • Content. Spam, scams and malicious messages.
  • Prompt protection. Injection, jailbreaks and tool or agent abuse in your AI product.
  • No rules to tune. One endpoint; send any mix of email, IP, phone, username, device or text.

Organizations live inside the console. Members share one credit wallet while admins set budgets, policies and security — billed per seat, free for up to 3 members.
